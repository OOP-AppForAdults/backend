# 성인을 위한 필수 상식 가이드 프로그램 (Backend)

기초 예절 및 사회 상식을 학습할 수 있는 데스크톱 애플리케이션의 백엔드 리포지토리입니다. 사지선다형 퀴즈와 카드 분류 게임의 핵심 비즈니스 로직, 데이터 관리, 학습 이력 저장을 담당합니다.

## 주요 기능 (Core Features)

* **문제 데이터 관리 (Question Management)**
  * 기초 예절 및 사회 상식 카테고리별 문제 데이터 제공 및 관리
  * 게임 유형별(사지선다형, 카드 분류형) 문제 객체 생성 및 할당
* **게임 비즈니스 로직 (Game Logic & Scoring)**
  * 사용자의 입력값에 대한 정답/오답 판별 로직 구현
  * 사지선다형 퀴즈: 실시간 정답/오답 개수 및 최종 점수 계산
  * 카드 분류 게임: 분류 영역 일치 여부 검증 및 타임어택 종료 후 점수 정산
* **파일 입출력 기반 데이터 저장 (File I/O Data Persistence)**
  * 게임 종료 후 사용자별 문제 풀이 결과 및 최종 점수 파일 저장
  * 오답 기록(오답 노트) 및 누적 학습 이력 파일 읽기/쓰기 구현

## 백엔드 개발 역할 분담 제안(26.11.10/황지현)

각자 하나의 게임 유형을 처음부터 끝까지 책임지는 방식으로, 독립적인 작업이 가능해 병렬 개발 속도가 빠릅니다.

* **개발자 A (사지선다형 퀴즈 & 공통 데이터 담당):**
  * 사지선다형 문제 데이터 모델링 및 정답/오답 판별, 점수 계산 로직
  * 공통 파일 입출력 유틸리티(I/O 클래스) 기본 세팅
* **개발자 B (카드 분류 게임 & 사용자 이력 담당):**
  * 카드 분류 문장 데이터 모델링 및 분류 일치 여부 검증 로직
  * 타임어택 종료 후 점수 정산 로직
  * '개발자 A'이 세팅한 입출력 유틸리티를 활용해 오답 노트 및 최종 학습 이력 저장 기능 완성
* **개발자 C~ (추가 기술적 기능 담당):**
  * 개발 과정에서 추가되는 기능들(예: 계정 생성을 통한 로그인 기능 등)을 자율적으로 배분


## 폴더 구조 (Directory Structure)
```text
src/
 ┣ data/         # 파일 입출력(I/O) 및 데이터 저장소 접근 로직
 ┣ domain/       # 문제, 사용자 점수, 학습 이력 등 객체 모델
 ┣ service/      # 정답 판별, 점수 계산 등 핵심 비즈니스 로직
 ┗ utils/        # 파일 읽기/쓰기 유틸리티 및 공통 함수
